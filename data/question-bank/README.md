# RISE question bank — canonical dataset

These five CSV files are the **canonical, checked-in source of truth** for
the imported RISE question bank (1,840 questions, 109 concepts, 68
misconceptions, 204 prerequisite edges, spanning 14 chapters). The
application loads directly from these files at module-load time — see
`src/domain/rise/` — rather than from a hand-transcribed TypeScript copy,
so there is exactly one place this content is authored.

## Provenance

This data was **not** generated by this repository's own build process.
It was produced by a separate "RISE Adaptive Mathematics Tutor" Python
generation pipeline, run in an external sandboxed environment
(hardcoded paths under `/home/claude/rise/` in its own `build.py`), and
dropped into this repo's working tree under `research-data/Question
bank/` (14 chapter folders of incremental checkpoints) and
`docs/perp_files/` (the original Stage A/B pilot package: taxonomy
CSVs, JSON Schema, design report). Neither of those source directories
is itself canonical — they're kept as historical/audit records. See
`MANIFEST.json` for exact source paths, counts, hashes, and the
compatibility checks run before integration.

**Do not edit these CSVs by hand.** They are copies of an external
pipeline's validated output. If the bank needs to change, that should
happen upstream (regenerate via the RISE pipeline) and be re-imported
here as a new version (`-v2`, etc.), not hand-patched in place — the
same stable-id discipline this project already applies to its original
161-question bank (see `CLAUDE.md` constraint 9) applies here too:
`question_id`, `concept_id`, and `misconception_id` values are joined on
by research analysis and must not be silently renumbered.

## What's here

| File | Rows | Content |
|---|---|---|
| `canonical-question-bank-v1.csv` | 1,840 | The complete question bank: every field needed to render, grade, and research-tag a question. |
| `canonical-question-bank-validation-v1.csv` | 1,840 | One audit row per question (schema/math/duplicate/render checks), row-aligned 1:1 with the question bank by `question_id`. |
| `concept-taxonomy-v1.csv` | 109 | Concept id, name, owning chapter, description, prerequisites, curriculum level. |
| `misconception-taxonomy-v1.csv` | 68 | Misconception id, name, description, the concepts it relates to, an example error, and the correct reasoning. |
| `prerequisite-edges-v1.csv` | 204 | Directed `prerequisite -> dependent` edges over the 109 concepts (verified acyclic). |

## Known, documented limitations (carried over from the source data)

- **Zero independent human review and zero empirical validation** on any
  of the 1,840 questions — every one is machine-authored and
  machine-checked only (see the per-question `validation_status` column
  and the pilot package's own `README-2.md`). Treat every question as
  provisional until a human reviews it.
- **Difficulty is author-assigned, not calibrated** — `difficulty_basis`
  is `author_assigned_not_empirically_calibrated` for all 1,840 rows.
- **One question** (see `docs/development-log.md`'s RISE integration
  entry for its id) has `validation_status:
  author_reviewed_math_not_automatically_verified` rather than
  auto-verified — its mathematics was checked by the original author
  but not by an executable check. It is not flagged as wrong, only as
  not machine-verified the way the other 1,839 are.
- **344 question pairs are flagged as lexically near-duplicate** (see
  the source's `near_duplicate_flags_checkpoint.csv`, not copied here to
  keep this directory to the authoritative question/curriculum data
  only) — every flagged pair was judged cross-family by the original
  author, meaning structurally distinct despite surface wording
  similarity, but that judgment was not independently re-reviewed.
