## Does the pipeline execute end to end?

**For a pilot-scale run: yes**, demonstrated by the actual recorded 13,560-run, 0-failure pilot output. **For the confirmatory study the protocol is designed to produce: no** — blocked on the missing approval file, and even past that gate, the analysis side (`analysis/stats.py`, independent verifier) that would turn a confirmatory run's raw output into the protocol's actual hypothesis tests does not exist yet. The research pipeline can currently answer "does the code run and produce plausible-looking numbers at small scale" (yes) but not "what does the confirmatory experiment conclude" (no apparatus exists yet to conclude anything).

## Simulated learners vs. real educational effectiveness

**SOURCE VERIFIED, correctly separated.** Every simulator (`src/research/phase8/simulator/s1.ts`..`s4.ts`) generates a synthetic learner against a known, code-defined ground-truth mastery process (`trueGraph.ts`) — this is explicitly never conflated with real student data anywhere this audit checked: the Researcher Workspace pages that display pilot numbers consistently caption them "simulated learners," "pilot-scale precision data," or "never a performance comparison," and the student-facing Workspace never reads from `research-output/` or `docs/phase8/` (confirmed in `SESSION_STATE_AND_PERSISTENCE.md` §1). No code path in this repository uses a Phase 8 simulated outcome to make a claim about real-world educational effectiveness.
